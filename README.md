# aerisk-fvlz

Reproducible evaluation of safeguarded dispatch policies in the
Fuerteventura–Lanzarote (FV–LZ) island power system.

This package accompanies the manuscript *Safe reserve scheduling with a
risk-adaptive safeguard in a two-node island power system: conformally
calibrated uncertainty and selective conservatism*. Every figure and every
number published in the manuscript is generated by this code from a single
results file; nothing is transcribed by hand.

## What it contains

- `aerisk_fvlz/system.py` — physical definition of the two-node FV–LZ system.
  All structural parameters come from official primary sources and are
  declared with their traceability; variable costs and emission factors are
  derived, not postulated.
- `aerisk_fvlz/world.py` — stochastic generator of hourly realizations,
  calibrated against the official 2025 magnitudes and audited by
  `calibration_report`. The hourly series are synthetic; no conclusion rests
  on unaudited absolute levels.
- `aerisk_fvlz/forecast.py` — gradient-boosted quantile regression with
  multiplicative split-conformal recalibration, trained, calibrated, and
  evaluated on three disjoint sets of realizations.
- `aerisk_fvlz/dispatch.py` — hourly commitment and dispatch simulator with an
  iterated, deliverable N-1 criterion, the risk gate, and the asymmetric
  non-relaxation ratchet. Six policies: A deterministic, B safeguarded,
  C permanently robust, D conservative, E static reserve rule, F uncertainty
  budget.
- `aerisk_fvlz/campaign.py` — orchestration of the eight experimental blocks
  (calibration, forecasting validation, main comparison, penetration sweep,
  error sensitivity, gate trade-off, contingencies, ablations).
- `aerisk_fvlz/stats.py` — paired inference: bootstrap confidence intervals,
  Wilcoxon signed-rank test, paired effect size, probability of superiority,
  Holm–Bonferroni correction.
- `aerisk_fvlz/benchmark.py` — exact mixed-integer unit commitment on
  representative weeks, used to bound the gap of the merit-order heuristic.
- `aerisk_fvlz/figures.py` — generation of the twelve manuscript figures with
  a geometric anti-collision audit.
- `aerisk_fvlz_sim.html` — self-contained executable test bench
  (supplementary interactive material).
- `manuscript/` — manuscript and supplementary material (Markdown sources).
- `figures/` — the twelve figures as published (PDF vector and 600 dpi PNG).
- `results/campaign_results.json` — results file from which every figure is
  built.

## Installation and full reproduction

    pip install -e .
    aerisk-fvlz all --outdir results

Subcommands: `calibration` (generator audit), `campaign` (experimental
blocks, resumable with `--parts`), `figures` (rebuild all figures from the
results file), `all`.

## Tests

    python -m pytest -q

The test battery checks the properties identified as critical: full billing
of start-ups, policy independence, N-1 criterion convergence to a fixed
point, hour-by-hour non-relaxation, balance consistency, conformal coverage
behavior, and seed determinism.

## Note on the results schema

The field names of `campaign_results.json` (e.g. `demanda_anual_GWh`,
`producible_renovable_GWh`, `consigna determinista`) are retained from the
2.x series in their original Spanish form as stable schema identifiers, so
that results files produced by earlier versions remain readable. All prose —
code comments, docstrings, figures, and documentation — is in English as of
version 2.2.0.
